## 📌 Проект 1: 🏦 Система управления вкладами (BankSystem)

**Задача**: Реализовать систему Сбербанка с функциями управления вкладчиками.

### ✅ Функциональность:

- **Создание счетов** - открытие лицевых счетов с указанием:
  - Номер лицевого счета (уникальный идентификатор)
  - Паспортные данные вкладчика
  - ФИО (полное имя)
  - Категория вклада (5 типов: Стандартный, Премиум, VIP, Студентов, Пенсионеров)
  - Первоначальная сумма депозита
  
- **Операции с деньгами**:
  - ✅ **Пополнение счета** (приём денег)
  - ✅ **Снятие со счета** (выдача денег с проверкой баланса)
  - ✅ Проверка баланса и истории операций
  - ✅ Валидация всех операций
  
- **Автоматическое начисление процентов**:
  - Разные ставки для каждой категории:
    - Стандартный: 2.5% годовых
    - Премиум: 4.0% годовых
    - VIP: 5.5% годовых
    - Студентов: 3.0% годовых
    - Пенсионеров: 3.5% годовых
  - Вычисление процентов с учётом дней, прошедших с последней операции
  - Автоматическое добавление начисленной суммы к балансу

- **Управление счетами**:
  - Просмотр всех счетов в таблице (StringGrid)
  - Удаление счетов (с подтверждением)
  - Отображение даты/времени последней операции
  - Логирование всех операций с временными метками

### 📁 Структура проекта:

```
lazarus-tasks/BankSystem/
├── BankSystem.lpr          # Главный файл проекта (точка входа)
├── MainBankForm.pas        # Главная форма с UI и обработчиками
├── BankData.pas            # Модуль логики работы с вкладами
└── MainBankForm.lfm        # Дизайн формы (автогенерируемый)
```

### 🎮 Кнопки и элементы управления:

**Вкладка 1: "Создание счета"**
- `edtAccountNumber` - номер счета (текстовое поле)
- `edtPassport` - номер паспорта
- `edtFullName` - ФИО вкладчика
- `cbCategory` - выпадающий список категорий
- `edtInitialAmount` - начальная сумма
- `btnCreateAccount` - **кнопка "Создать счет"**
- `mmoStatus` - консоль логирования операций

**Вкладка 2: "Операции"**
- `edtOpAccountNumber` - номер счета для операции
- `edtAmount` - сумма операции
- `btnDeposit` - **кнопка "Пополнить"** (приём денег)
- `btnWithdraw` - **кнопка "Снять"** (выдача денег)
- `btnApplyInterest` - **кнопка "Начислить проценты"**

**Вкладка 3: "Просмотр счетов"**
- `sgAccounts` - таблица со всеми счетами (7 колонок)
- `btnRefreshAccounts` - **кнопка "Обновить"**
- `btnDeleteAccount` - **кнопка "Удалить выбранный счет"**

**Навигация**
- `btnPageCreate` - переход на страницу создания
- `btnPageOperations` - переход на страницу операций
- `btnPageView` - переход на страницу просмотра

### 💡 Примеры использования:

**Создание счета:**
1. Введите номер счета: `40817810012345678901`
2. Введите паспорт: `0123456789`
3. Введите ФИО: `Иванов Иван Иванович`
4. Выберите категорию: `Премиум`
5. Введите начальную сумму: `10000`
6. Нажмите **"Создать счет"**

**Пополнение счета:**
1. Перейдите на вкладку "Операции"
2. Введите номер счета: `40817810012345678901`
3. Введите сумму: `5000`
4. Нажмите **"Пополнить"**

**Начисление процентов:**
1. Введите номер счета
2. Нажмите **"Начислить проценты"**
3. Система автоматически рассчитает процент на основе дней

## 📌 Проект 2: 🏭 Визуализация конвейера (Conveyor)

**Задача**: Изобразить действующий конвейер, транспортирующий однотипные предметы.

### ✅ Функциональность:

- **Анимированный конвейер** с движущейся лентой и визуальным эффектом
  
- **Три типа предметов**:
  - 📦 Коробки (прямоугольники)
  - 🔶 Цилиндры
  - ⚪ Сферы
  
- **Управление параметрами**:
  - Регулятор скорости (TrackBar: 1-50)
  - Выбор типа предмета (ComboBox)
  - Выбор цвета предмета (TColorDialog)
  
- **Управление конвейером**:
  - ✅ **"Старт"** - запуск анимации
  - ✅ **"Стоп"** - остановка конвейера
  - ✅ **"Добавить предмет"** - размещение нового предмета на ленте
  - ✅ **"Очистить"** - удаление всех предметов
  - ✅ Счётчик количества предметов на конвейере
  
- **Визуальные эффекты**:
  - Движущиеся полосы на ленте конвейера
  - Реалистичная отрисовка 3D-подобных объектов
  - Поддержка конвейера столбами (pillars)
  - Плавная анимация 30 FPS
  - Объекты исчезают при выходе за правый край экрана

### 📁 Структура проекта:

```
lazarus-tasks/Conveyor/
├── Conveyor.lpr            # Главный файл проекта
├── ConveyorMain.pas        # Главная форма с визуализацией
└── ConveyorMain.lfm        # Дизайн формы (автогенерируемый)
```

### 🎮 Кнопки и элементы управления:

**Управление скоростью**
- `trackSpeed` - TrackBar для регулировки (1-50)
- `lblSpeedValue` - отображение текущей скорости в реальном времени

**Выбор предметов**
- `cbItemType` - выпадающий список: Коробка / Цилиндр / Сфера
- `btnItemColor` - **кнопка выбора цвета** (открывает диалог)

**Управление конвейером**
- `btnStart` - **кнопка "Старт"** (запуск анимации)
- `btnStop` - **кнопка "Стоп"** (остановка)
- `btnAddItem` - **кнопка "Добавить предмет"** (добавляет с левого края)
- `btnClear` - **кнопка "Очистить"** (удаляет все предметы)
- `edtItemCount` - счётчик количества предметов

**Область визуализации**
- `imgConveyor` - TImage для рисования конвейера и объектов

### 💡 Примеры использования:

**Запуск конвейера:**
1. Выберите тип предмета (ComboBox): `Коробка`
2. Выберите цвет: нажмите кнопку, выберите красный
3. Нажмите **"Старт"** для запуска конвейера
4. Нажимайте **"Добавить предмет"** для размещения коробок

**Изменение скорости:**
1. Переместите слайдер `trackSpeed` влево/вправо
2. Скорость изменится в реальном времени

**Использование разных предметов:**
1. Выберите `Цилиндр` в ComboBox
2. Нажмите **"Добавить предмет"**
3. Выберите другой цвет
4. Добавьте ещё предметы

## 🚀 Как запустить проекты

### Требования:
- **Lazarus IDE** (версия 2.0 или выше)  
- **Free Pascal Compiler** (fpc)
- Операционная система: Windows / Linux / macOS

### Запуск BankSystem:

1. Откройте **Lazarus IDE**
2. Откройте файл `lazarus-tasks/BankSystem/BankSystem.lpr`
3. Нажмите **F9** или выберите **Run → Run**
4. Введите данные вкладчика и нажимайте кнопки

### Запуск Conveyor:

1. Откройте **Lazarus IDE**
2. Откройте файл `lazarus-tasks/Conveyor/Conveyor.lpr`
3. Нажмите **F9** или выберите **Run → Run**
4. Используйте кнопки для управления конвейером

## 🏗️ Архитектура и технические детали

### BankSystem:

**Модуль BankData.pas:**
- Класс `TBankAccountManager` - основной менеджер для управления счетами
- Тип `TBankAccount` - запись с полями счета
- Тип `TDepositCategory` - перечисление категорий вкладов
- Методы:
  - `CreateAccount()` - создание нового счета
  - `DeleteAccount()` - удаление счета
  - `Deposit()` - пополнение
  - `Withdraw()` - снятие денег
  - `ApplyInterest()` - начисление процентов
  - `GetInterestRate()` - получение ставки по категории

**Модуль MainBankForm.pas:**
- Класс `TMainBankForm` - основная форма с UI
- TNotebook - для переключения между тремя страницами
- TStringGrid - таблица счетов
- TMemo - логирование операций
- Обработчики событий для всех кнопок

### Conveyor:

**Модуль ConveyorMain.pas:**
- Класс `TConveyorMainForm` - форма с визуализацией
- Тип `TConveyorItem` - запись предмета на конвейере
- Методы рисования:
  - `DrawConveyor()` - рисует саму ленту конвейера
  - `DrawBox()` - рисует коробку
  - `DrawCylinder()` - рисует цилиндр
  - `DrawSphere()` - рисует сферу
  - `DrawItems()` - рисует все предметы
- Анимация с TTimer (30 FPS)
- Динамический массив для хранения предметов
